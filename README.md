# Contextator

A private-alpha iPhone and Chrome workflow for choosing what context to share with a browser tool.

[Contextator at Burrito’s Labs](https://burritoslabs.com/catalogue/contextator/)

## Technology

Swift and SwiftUI on iPhone, TypeScript and Chrome Manifest V3 on the browser.

## Architecture

The iPhone holds the context vault. A request enters a review flow and only approved context is made available to the browser extension for the intended insertion.

## Product behavior

The design keeps context selection and approval visible, with an encrypted handoff between components.
